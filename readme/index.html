如何创建github page

步骤

  • note文件夹下运行mkdocs serve
  • note文件夹下运行mkdocs build
  • note文件夹下运行mkdocs gh-deploy
  • 不必运行 git push！
  • 这种方法会自动将代码推送到gh-deploy分支
